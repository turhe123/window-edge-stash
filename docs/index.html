Features

One job, done properly.

WindowEdgeStash does only edge stashing, and gives you control over how it behaves.

Global stash and unstash hotkeys

Stash the focused window with Control-Option-S and restore it with Control-Option-U. Both hotkeys can be re-recorded in Settings.

Hover to reveal

Rest the pointer on the strip for your chosen delay and the window slides into view, raised and focused. It slides back when the pointer leaves.

Several windows per edge

Stash as many windows as you like. Strips on the same edge stack so each one keeps its own hover area.

Multi-display aware

Edges that border another display are skipped, so a window is never stashed into the space between your screens.

Tunable behavior

Set strip width from 2 to 20 points, reveal delay up to 1000 ms and animation duration up to 600 ms. Optionally hide windows when focus moves to another app.

Menu bar control, no Dock icon

The menu lists stashed windows by app and title, each with Unstash, plus Unstash All. A subtle line highlights the edge while you hover a strip.

Install

Up and running in a minute.

WindowEdgeStash is open source and not notarized with a paid Apple Developer ID, so macOS needs one extra step the first time.

  1. Download WindowEdgeStash-macOS.zip and unzip it.
  2. Move WindowEdgeStash.app to your Applications folder.
  3. Clear the quarantine flag once, then right-click the app and choose Open:
    xattr -cr /Applications/WindowEdgeStash.app
  4. When prompted, grant Accessibility access in System Settings Privacy Security Accessibility so the app can move windows.

FAQ

Questions, answered.

Is WindowEdgeStash really free and open source?

Yes. It is released under the MIT license and the full source is on GitHub. There is no account, no server and no analytics, and you can build it yourself with Xcode.

What permissions does it need?

Accessibility, which it uses to read and move other apps' windows. Launch at login is optional and only registered if you turn it on. It does not request Screen Recording, camera, microphone or network access.

Where is my data stored?

Your settings are stored locally in the app's preferences on your Mac. The list of stashed windows lives only in memory, so every stashed window is restored to its original position when you quit the app.

Why is the app not notarized?

Notarization requires a paid Apple Developer account, which this free project does not have. Right-click the app and choose Open once to launch it, or build it from source with Xcode.

Was this written by AI?
